# A Space for the Unbound — Fan-Made Showcase Website
**Karya Lomba Web Development IT FEST UNW 2026**  
**Tema:** *"Immersive Gaming Experience Through Web Technology"*

---

## 🌟 Tentang Proyek
Website ini merupakan **fan-made showcase** interaktif untuk game naratif petualangan Indonesia pemenang penghargaan dunia, **"A Space for the Unbound"** yang dikembangkan oleh **Mojiken Studio** (Surabaya) dan diterbitkan oleh **Toge Productions**.

Website dirancang dengan mengedepankan pengalaman imersif bertema **"Malam Loka"** dan transisi **"Dive Mind"**, memadukan estetika pixel art retro 90-an dengan performa teknologi web modern.

---

## 🚀 Fitur Utama & Kepatuhan Juknis
- **100% Bebas CMS & Template Premium**: Dibangun dari awal (*from scratch*) menggunakan Next.js dan Tailwind CSS sesuai ketentuan Juknis D.4.
- **5 Section Wajib Terpenuhi**:
  1. **#home (Hero)**: Latar kanvas bintang bergerak (*animated starfield*), tipografi pixel display Silkscreen, dan lencana penghargaan.
  2. **#characters**: Kartu interaktif tokoh utama (Atma & Raya) dengan *tilt hover*, *border glow*, dan cuplikan tokoh pendukung kota Loka.
  3. **#gameplay**: Transisi warna sinematik ke palet surreal *Dive Mind*, 4 kartu mekanik utama, dan pemutar video in-game.
  4. **#news**: Linimasa milestone pencapaian internasional (2020 s.d. 2025) dengan animasi *scroll-reveal* responsif.
  5. **#play**: Etalase tautan resmi multi-platform (Steam, PlayStation, Xbox, Switch, iOS) dan spesifikasi teknis game.
- **Interaktivitas Multimedia**: Modal video interaktif yang dapat memutar 7 video trailer lokal berformat WebM/MP4 ringan dengan opsi *playlist selector* dan fallback embed YouTube.
- **Performa Ringan**: Seluruh aset gambar telah dikonversi ke format **WebP modern** (rata-rata 20 KB – 90 KB) dan video trailer terkompresi hemat kuota.
- **Smooth Scroll**: Menggunakan Lenis untuk sensasi gulir layar yang mewah dan halus.
- **Penuh Tanggung Jawab Hak Cipta**: Dilengkapi *disclaimer* legalitas non-komersial dan atribusi kredit penuh kepada Mojiken Studio & Toge Productions (Juknis D.11).

## 🛠️ Tech Stack
- **Framework**: Next.js 14+ (App Router, React 18, TypeScript)
- **Styling**: Tailwind CSS 3 (Custom Tokens: Malam Loka & Dive Mind)
- **Animasi & Efek**: Framer Motion, HTML5 Canvas Starfield
- **Smooth Scroll**: Lenis
- **Ikonografi**: Lucide React & React Icons
- **Tipografi**: Google Fonts (`Silkscreen`, `Plus Jakarta Sans`, `Caveat`)

## 💻 Panduan Instalasi & Menjalankan Lokal

### 1. Prasyarat
- Node.js versi 18+ atau 20+ (Direkomendasikan Node.js v20/v22)
- npm atau pnpm

### 2. Langkah Instalasi
```bash
# Clone repositori
git clone https://github.com/username/fanmade-a-space-for-the-unbound.git
cd fanmade-a-space-for-the-unbound

# Install dependensi
npm install
# atau
pnpm install

# Jalankan server pengembangan lokal
npm run dev
# atau
pnpm dev
```

Buka peramban Anda di: [http://localhost:3000](http://localhost:3000)

### 3. Build untuk Produksi
```bash
npm run build
npm run start
```
